# Unidad 33 — Proyecto final
Construye aplicación web sin framework.

## Requisitos
- HTML/CSS existente o propio;
- módulos ES;
- estado;
- DOM/eventos;
- formulario;
- API o fuente asíncrona;
- loading/error/empty;
- cancelación cuando aplique;
- almacenamiento cuando aporte;
- accesibilidad dinámica;
- pruebas;
- npm;
- README reproducible.

No se evalúa por cantidad de APIs usadas, sino por claridad y comportamiento.
