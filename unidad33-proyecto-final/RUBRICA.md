# Rúbrica del proyecto (100 puntos)

[Proyecto](PRACTICA.md) · [Índice](../README.md)

| Criterio | Máximo | Evidencia para logro completo |
|---|---:|---|
| Dominio y datos | 20 | Contratos, límites, id, invariantes y conservación de origen probados |
| Interacción y estados | 20 | CRUD/filtros/edición y red reproducibles sin éxito ficticio |
| Persistencia y errores | 20 | JSON validado, carga corrupta y guardado fallido tratados |
| Acceso y presentación | 20 | Teclado, foco, nombres, anuncios, reflujo y texto seguro |
| Pruebas y documentación | 20 | Casos normales/límites/fallos, ejecución reproducible y límites claros |

Asigna 20 si el criterio se demuestra completo, 10 si se demuestra parcialmente con fallos identificados y 0 si no hay evidencia o la función principal no puede comprobarse. Puedes usar valores intermedios explicando la evidencia. Un buen puntaje en otra dimensión no elimina una barrera grave de acceso ni una pérdida de datos.
