# Checklist final

[Proyecto](PRACTICA.md) · [Rúbrica](RUBRICA.md) · [Índice](../README.md)

- [ ] La ejecución comienza desde una copia limpia con instrucciones reproducibles.
- [ ] No hay imports, recursos o destinos locales ausentes.
- [ ] Los contratos de datos están documentados y validados.
- [ ] Las funciones de dominio no dependen de DOM/Storage.
- [ ] Las acciones usan id, también en vistas filtradas.
- [ ] Editar/cancelar/eliminar afectan solo la tarea correcta.
- [ ] Carga corrupta y guardado fallido tienen estados honestos.
- [ ] El catálogo distingue HTTP, JSON, esquema y red.
- [ ] Timeout y cancelación limpian recursos.
- [ ] Una respuesta antigua no sobrescribe la solicitud vigente.
- [ ] El render usa texto para entradas y no ejecuta marcado.
- [ ] Todos los controles tienen nombre y acceso por teclado.
- [ ] El foco se recupera cuando desaparece su control.
- [ ] Los anuncios son pertinentes y no reconstruyen toda la experiencia.
- [ ] 320 px, tamaños intermedios y texto/zoom ampliados fueron revisados.
- [ ] No hay excepciones inesperadas en recorridos de aceptación.
- [ ] Las pruebas incluyen normales, límites, inválidos y fallos externos.
- [ ] La publicación, si existe, aclara qué API requiere y qué es estático.
- [ ] Los límites de guardado local y ausencia de respaldo están claros.

Registra fecha, navegador, condiciones y evidencia. Las pruebas automáticas no sustituyen revisar zoom real o lector de pantalla cuando esté disponible.
