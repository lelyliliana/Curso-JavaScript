# Unidad 01 — Valores, tipos y variables
Primitivos: string, number, bigint, boolean, undefined, symbol, null. Objetos son referencias.
```js
const nombre="Ana"; let contador=0;
```
Usa const cuando no reasignas y let cuando sí. `typeof null` devuelve "object" por una particularidad histórica. **Reto:** inspecciona tipos y distingue mutar un objeto de reasignar la variable.
