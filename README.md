# Curso de JavaScript desde cero

**Versión 1.0**

Curso abierto para aprender **JavaScript moderno** desde los fundamentos del lenguaje hasta programación en el navegador, asincronía, consumo de APIs, módulos, almacenamiento, manejo de errores y pruebas.

## Requisito recomendado

[Curso de HTML y CSS desde cero](https://github.com/lelyliliana/Curso-HTML-CSS)

## Objetivo

Al finalizar podrás:

- comprender tipos, coerción y operadores;
- utilizar decisiones, ciclos y funciones;
- trabajar con arrays y objetos;
- comprender scope, closures y `this`;
- utilizar destructuring, spread/rest y módulos;
- manipular el DOM;
- manejar eventos y formularios;
- aplicar accesibilidad a interfaces dinámicas;
- trabajar con Promises y async/await;
- consumir APIs con fetch;
- manejar errores, abortar solicitudes y representar estados de carga;
- utilizar almacenamiento web con criterio;
- organizar aplicaciones en módulos;
- utilizar npm;
- escribir pruebas;
- construir una aplicación web completa sin framework.

## Metodología

Concepto → ejemplo → código → navegador/DevTools → errores → accesibilidad → ejercicios → reto.

## Alcance

Este curso enseña JavaScript sin framework. React se mantiene como curso independiente.

## Principio

> Aprender JavaScript no es memorizar métodos: es comprender datos, ejecución, asincronía y cómo el código modifica una interfaz sin romper su comportamiento ni accesibilidad.
