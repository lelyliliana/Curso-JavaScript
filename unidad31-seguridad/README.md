# Unidad 31 — Seguridad web básica para frontend
El frontend es observable por el usuario.
- no almacenes secretos;
- evita inyectar HTML no confiable;
- valida/escapa según contexto;
- comprende que CORS no es autenticación;
- HTTPS no hace confiable un dato.
**Reto:** identifica riesgos XSS conceptuales en renderizado de comentarios.
