# Diagnóstico JavaScript

## Carga
¿HTML y módulos responden 200?

## Sintaxis
¿Console muestra error?

## Datos
¿tipo/valor es el esperado?

## DOM
¿selector encuentra elemento?

## Evento
¿listener está registrado y evento ocurre?

## Red
¿request, status y body son correctos?

## Asincronía
¿Promise se resuelve/rechaza? ¿hay carrera/cancelación?

## Render
¿estado y DOM coinciden?

## Regla
“No hace nada” no es diagnóstico. Localiza la primera capa donde deja de ocurrir lo esperado.
