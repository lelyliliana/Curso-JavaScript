# Glosario

[Índice](../README.md) · [Primera unidad](../unidad00-entorno/README.md)

| Término | Significado |
|---|---|
| Vinculación | Asociación de un nombre con un valor |
| Referencia | Valor que permite acceder a un objeto, con identidad propia |
| Coerción | Conversión de tipo realizada por una operación |
| Contrato | Entradas admitidas, salida, efectos y tratamiento de fallos |
| Función pura | Regla sin efectos externos ni dependencia de estado mutable externo |
| Closure | Función con acceso al entorno léxico conservado |
| Copia superficial | Nuevo contenedor con referencias compartidas en niveles anidados |
| Prototipo | Objeto usado en la relación de búsqueda de propiedades |
| DOM | Representación del documento disponible para interacción |
| Evento | Información de una acción o cambio procesado por listeners |
| Delegación | Manejo en un contenedor de eventos de descendientes |
| Estado | Datos y fase que representan la situación de la app |
| Render | Representación del estado en la interfaz |
| Promise | Resultado eventual de una operación |
| Microtarea | Trabajo encolado, como ciertas reacciones de Promises |
| async/await | Sintaxis para producir y esperar Promises |
| Cancelación | Solicitud de interrumpir una operación; no garantiza revertir efectos remotos |
| Carrera | Resultados cuya llegada puede contradecir la última intención |
| Timeout | Límite de espera de una operación |
| Esquema | Estructura y reglas de datos que se esperan |
| Origen | Combinación de esquema, host y puerto |
| Storage | Almacenamiento de texto del navegador por origen |
| Adaptador | Límite que conecta una responsabilidad con otra API |
| Módulo | Archivo con import/export y ámbito propio |
| Mock | Sustituto controlado para comprobar un contrato, sin demostrar integración real |
